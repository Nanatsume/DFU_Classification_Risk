4 Segmentation Mask (mask-aware features)
The paper's GLCM/LBP/HOG were designed for full-frame texture (no background). Since this dataset has pre-segmented objects on a solid background, an auto-detected foreground mask is offered here as an optional, disclosed deviation — so you can compare "full frame" vs "foreground only" side by side.
—
Threshold 127
Direction (which side is background) is auto-detected with Otsu's method — the side matching the image border is assumed to be background. The cutoff itself defaults to 0 (only pure-black pixels count as background), which matches solid-black-background product/object photos without needing to touch the slider. Drag it up if your background isn't pure black. In mask-aware mode: GLCM only counts a pixel pair if both pixels are foreground · LBP only computes a code if the centre pixel and all 8 neighbours are foreground · HOG zeroes out gradients that would cross into background and drops any 2×2 block whose foreground coverage is below 50%.

ZoneStatisticValue
Per-pixel code = Σₚ₌₀^(P−1) [I(pₙ) op I(center)] · 2ᵖ — robust to monotonic lighting changes since only the comparison matters, not the raw value. Uniform collapses any code with more than 2 circular 0↔1 transitions into one "non-uniform" bin (P(P−1)+3 symbols total). Rotation-invariant uniform goes further — uniform patterns are also grouped by number of 1-bits regardless of rotation, giving just P+2 symbols. Whichever encoding is selected, the same 8 statistics (Mean, Variance, Entropy, Skewness, Kurtosis, Energy, Contrast, Correlation) are computed over it — per zone in Regional mode (4 zones × 8 = 32).

PCA needs a dataset (multiple images), not one image — the descriptor is a single vector, and variance only means something across many of them. To keep this tractable in-browser with few samples (n ≪ d), it's solved via the Gram-matrix trick: eigen-decompose the small n×n similarity matrix instead of the huge d×d covariance matrix — mathematically equivalent for the non-zero eigenvalues. Caveat: with only a handful of session images this is illustrative, not a real benchmark — a proper PCA study needs a much larger, more diverse dataset than a live demo can hold.
